# Advanced Maths (Algebra, Geometry, Mensuration, Trigonometry, DI, Statistics): DSSSB TGT Revision Notes

## 1. One-page summary

- Of the 20 numerical-ability questions, about 6–8 come from this chapter: 1–2 algebra, 1–2 geometry, 1–2 mensuration, 1 trigonometry, 1–2 data interpretation or statistics.
- Most items are one-formula questions. Write the formula first, then substitute; this avoids sign and square-root slips.
- Check options by substitution: put simple values (x = 1, θ = 45°, a = 7 and b = 3) into the expression and see which option matches.
- Use π = 22/7 when the radius is a multiple of 7; otherwise keep π in the answer.

## 2. Algebra: identities and quadratics

| Identity | Use |
|---|---|
| (a ± b)² = a² ± 2ab + b² | a² + b² = (a + b)² − 2ab |
| a² − b² = (a + b)(a − b) | 103 × 97 = 100² − 3² |
| (a ± b)³ = a³ ± b³ ± 3ab(a ± b) | a³ − b³ = (a − b)³ + 3ab(a − b) |
| a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) | If a + b + c = 0, then a³ + b³ + c³ = 3abc |
| x + 1/x = k | x² + 1/x² = k² − 2; x³ + 1/x³ = k³ − 3k |
| x − 1/x = k | x² + 1/x² = k² + 2 |
| x² + 1/x² = m | x⁴ + 1/x⁴ = m² − 2 |

Quadratic ax² + bx + c = 0:

| Item | Formula |
|---|---|
| Roots | x = [−b ± √(b² − 4ac)] / 2a |
| Sum, product of roots | −b/a, c/a |
| Discriminant D = b² − 4ac | D > 0 distinct real, D = 0 equal, D < 0 no real roots |
| α² + β² | (α + β)² − 2αβ |

- x = 2 + √3 gives 1/x = 2 − √3, so x + 1/x = 4. Same trick for 3 + 2√2 (x + 1/x = 6).
- For two linear equations, substitute one variable or add/subtract to eliminate. Always back-check in both equations.

## 3. Geometry

| Fact | Formula / value |
|---|---|
| Sum of interior angles of an n-gon | (n − 2) × 180° |
| Exterior angles of any polygon | Total 360°; regular polygon each = 360°/n |
| Exterior angle of a triangle | Sum of the two interior opposite angles |
| Angle in a semicircle | 90° |
| Angle at centre | Twice the angle at the circumference on the same arc |
| Cyclic quadrilateral | Opposite angles add to 180° |
| Chord distance | d = √(r² − (chord/2)²) |
| Tangent length from external point | √(d² − r²); tangent ⟂ radius |
| Intersecting chords | AP × PB = CP × PD |
| Basic proportionality (Thales) | DE ∥ BC → AD/DB = AE/EC |
| Similar triangles | Area ratio = (side ratio)² |
| Right triangle | Median to hypotenuse = half the hypotenuse |
| Centroid | Divides each median in 2 : 1 from the vertex |
| Equilateral triangle side a | Height (√3/2)a; circumradius a/√3; inradius a/(2√3) |

Pythagorean triplets to remember: 3-4-5, 5-12-13, 7-24-25, 8-15-17, 9-40-41, 20-21-29.

## 4. Mensuration

| Shape | Area / volume | Surface |
|---|---|---|
| Triangle (Heron) | √[s(s − a)(s − b)(s − c)], s = (a + b + c)/2 | — |
| Equilateral triangle | (√3/4)a² | — |
| Rhombus | ½ d₁d₂; side = √[(d₁/2)² + (d₂/2)²] | — |
| Circle | πr²; circumference 2πr | — |
| Sector of angle θ | (θ/360)πr² | Arc = (θ/360)2πr |
| Cube | a³ | TSA 6a², LSA 4a² |
| Cuboid | lbh | TSA 2(lb + bh + hl); diagonal √(l² + b² + h²) |
| Cylinder | πr²h | CSA 2πrh; TSA 2πr(r + h) |
| Cone | (1/3)πr²h | CSA πrl; l = √(r² + h²) |
| Sphere | (4/3)πr³ | 4πr² |
| Hemisphere | (2/3)πr³ | CSA 2πr²; TSA 3πr² |

- Melting and recasting: volume stays the same. Number of small solids = big volume ÷ small volume.
- Path outside a rectangle of width w: (l + 2w)(b + 2w) − lb. Inside: lb − (l − 2w)(b − 2w).
- Percentage change in area when every length changes by x%: 2x + x²/100. Volume: use (1 + x/100)³.
- Common results: circle with circumference 44 has r = 7, area 154; 13-14-15 triangle has area 84.

## 5. Trigonometry

| θ | 0° | 30° | 45° | 60° | 90° |
|---|---|---|---|---|---|
| sin | 0 | 1/2 | 1/√2 | √3/2 | 1 |
| cos | 1 | √3/2 | 1/√2 | 1/2 | 0 |
| tan | 0 | 1/√3 | 1 | √3 | not defined |

| Identity | Consequence |
|---|---|
| sin²θ + cos²θ = 1 | 1 − sin²θ = cos²θ |
| sec²θ − tan²θ = 1 | sec θ + tan θ = k → sec θ − tan θ = 1/k |
| cosec²θ − cot²θ = 1 | cosec θ + cot θ = k → cosec θ − cot θ = 1/k |
| Complementary angles | sin(90° − θ) = cos θ; tan(90° − θ) = cot θ |
| sin A = cos B (both acute) | A + B = 90° |

Heights and distances: tan(elevation) = height / horizontal distance. Angle of elevation from the ground equals the angle of depression from the top (alternate angles). Shadow = h cot(sun's altitude).

- tan 10° tan 20° tan 70° tan 80° type products pair into tan θ cot θ = 1.

## 6. Data interpretation (tables)

| Quantity | Formula |
|---|---|
| Percentage | part / whole × 100 |
| Percent increase | (new − old) / old × 100 |
| Percent of another | A / B × 100 |
| Share in a year | item / total of that year × 100 |
| Average | total / number of items |
| Ratio | reduce by HCF |

- Add the totals row or column once and reuse it for every question in the set.
- Overall percentage = total part / total whole. Never average the individual percentages when group sizes differ.
- Approximate fractions: 1/6 = 16.67%, 1/7 = 14.29%, 1/8 = 12.5%, 1/9 = 11.11%, 1/11 = 9.09%, 1/12 = 8.33%.

## 7. Statistics

| Measure | Formula |
|---|---|
| Mean | Σx / n; grouped Σfx / Σf |
| Median | Middle value of ordered data; even count → average of two middle values |
| Mode | Most frequent value |
| Empirical relation | Mode = 3 Median − 2 Mean |
| Range | Maximum − minimum |
| Variance | Σ(x − mean)² / n |
| Standard deviation | √variance |
| Mean of first n natural numbers | (n + 1)/2 |

- Corrected mean: new total = old total − wrong value + correct value.
- Removing a value: removed = old total − new total.
- If every value is multiplied by k and then c is added, the mean becomes k × mean + c. The SD becomes |k| × SD (adding c does not change it).

## 8. Fifteen quick-revision one-liners

1. x + 1/x = k → x² + 1/x² = k² − 2.
2. a + b + c = 0 → a³ + b³ + c³ = 3abc.
3. Equal roots: b² = 4ac.
4. Sum of interior angles = (n − 2) × 180°; exterior angles total 360°.
5. Opposite angles of a cyclic quadrilateral add to 180°.
6. Tangent length = √(d² − r²).
7. Similar triangles: area ratio is the square of the side ratio.
8. Heron: s = half the perimeter; 13-14-15 gives 84.
9. Hemisphere TSA = 3πr²; cone CSA = πrl.
10. Melting keeps volume constant.
11. 10% increase in radius → 21% increase in area.
12. sec θ + tan θ = k → sec θ − tan θ = 1/k.
13. sin A = cos B → A + B = 90°.
14. Mode = 3 Median − 2 Mean.
15. Overall percentage = total part / total whole, not the average of percentages.

## 9. Five common traps

1. x − 1/x = k gives x² + 1/x² = k² + 2, not k² − 2. Check the sign of the given expression.
2. Using height instead of slant height in the cone's curved surface area (πrl, with l = √(r² + h²)).
3. Path questions: the outer rectangle adds 2w, not w, to each dimension.
4. Percent increase divided by the new value instead of the old value.
5. Reporting the variance when the standard deviation is asked (or the mean when the median is asked).
