# Verbal Reasoning: DSSSB TGT Revision Notes

## 1. One-page summary

- General Intelligence and Reasoning carries about 20 marks. Roughly 12-14 questions are verbal (series, coding, syllogism, relations, directions, ranking, statements) and the rest non-verbal.
- Scoring order: series and analogy (10-20 seconds each), then coding, ranking, direction and blood relation (30-45 seconds), then syllogism and statement questions (45-60 seconds), then clock and calendar.
- Always write the working on rough paper: a small diagram for direction, a family tree for relations, a line for ranking. Do not solve in your head.
- Negative marking is 0.25, so a question where you can eliminate two options is worth attempting.

## 2. Analogy and classification

- First name the relation, then apply it: worker : tool, tool : use, whole : part, creator : creation, person : place of work, cause : effect, animal : young one.
- Number analogies: test squares, cubes, n(n + 1), n^2 + 1 or n^3 + 1 before anything else. Example: 5 : 30 :: 7 : ? Here 5 x 6 = 30, so 7 x 8 = 56.
- Letter analogies: check a fixed shift (every letter +2), then reverse order, then mirror letters.
- Odd one out: look for category first (fruit, vegetable, mammal), then number property (prime, square, multiple), then letter gaps.
- Example: 17, 23, 29, 39. Three are prime; 39 = 3 x 13 is the odd one.

## 3. Number and letter series

| Pattern | Example | Next |
|---|---|---|
| Constant difference | 7, 12, 17, 22 | 27 |
| Increasing difference | 2, 5, 10, 17, 26 (+3, +5, +7, +9) | 37 |
| Squares / cubes | 1, 4, 9, 16 / 1, 8, 27 | 25 / 64 |
| n^2 + 1 or n^2 - 1 | 2, 5, 10, 17 | 26 |
| Multiply and add | 3, 7, 15, 31 (x2 + 1) | 63 |
| Factorial-type | 1, 2, 6, 24 | 120 |
| Alternate series | 3, 10, 6, 20, 9, 30 | 12 |

- Check the differences first, then the ratios, then the squares and cubes, then a two-step rule (multiply and add), then two interleaved series.
- Letters: use A = 1 ... Z = 26. Learn EJOTY = 5, 10, 15, 20, 25 and that opposite letters add to 27 (A + Z, B + Y, M + N).
- Letter-position trick: write the numbers under the letters, find the number pattern, convert back. Example: A, C, F, J, O: gaps +2, +3, +4, +5, so next gap +6: O (15) to U (21).
- Multi-letter groups: study each position separately (first letters, second letters, third letters).

## 4. Coding-decoding

- Types: letter shift (+1, -1, +2), reverse alphabet (A to Z), reversal of word, position sum, substitution from given statements, number codes.
- Example (shift): MIND coded +2 gives OKPF. For a code of "+1, +2, +3" shifts, apply the shifts position by position.
- Example (sum): if CAT = 24 using A = 1, B = 2 then CAT = 3 + 1 + 20 = 24 and DOG = 4 + 15 + 7 = 26.
- Language-code questions: find the common word between two statements; its code is the common symbol. Eliminate until one word remains.
- Example: "sky is blue" = ro mi ta, "blue sea deep" = la mi su, "deep sky" = ta la. Deep = la (common in 2 and 3), sky = ta, blue = mi, so sea = su.
- Number-letter coding: write a small table of letter to digit first, then translate the target word.

## 5. Syllogism

| Statement pair | Valid conclusion |
|---|---|
| All A are B + All B are C | All A are C |
| All A are B + Some B are C | None |
| Some A are B + All B are C | Some A are C |
| All A are B + No B is C | No A is C |
| No A is B + All B are C | Some C are not A |
| Some A are B + No B is C | Some A are not C |
| No A is B + No B is C | None |
| Some A are B + Some B are C | None |

- Conversions: All A are B gives Some B are A. Some A are B gives Some B are A. No A is B gives No B is A. "Some A are not B" has no conversion.
- Complementary pair: if neither conclusion follows but they are "Some X are Y" and "No X is Y" (or "All X are Y" and "Some X are not Y"), then "Either I or II follows".
- Draw the Venn diagram with the minimum overlap; a conclusion is valid only if it holds in every possible diagram.
- Do not use outside knowledge: "All cats are dogs" is taken as true.

## 6. Blood relation

- Draw a family tree: squares for males, circles for females, a line for marriage, a vertical line for children.
- Key terms: father's or mother's brother is uncle (chacha, tau, mama); father's sister is bua; mother's sister is mausi; wife of brother is bhabhi; brother of wife is brother-in-law (sala).
- "My father's son" with no brother means myself. "Only daughter of my mother" means myself (if I am female).
- Notation questions (A + B, A - B): translate each symbol into its meaning, then chain from left to right.
- Example: "He is the son of my father's sister" means he is the son of the speaker's bua, that is, the speaker's cousin.

## 7. Direction and distance

- Draw the path from the starting point, mark each turn as a quarter-turn (left of east is north).
- Net displacement: add east and west with signs, add north and south with signs, then use Pythagoras. Common triples: 3-4-5, 5-12-13, 8-15-17, 7-24-25.
- Shadow rule: at sunrise the shadow falls to the west; in the evening it falls to the east; at noon it falls towards the north (in India).
- Rotation: clockwise adds to the compass heading, anticlockwise subtracts. Take north = 0, east = 90, south = 180, west = 270.
- Example: facing east, turn 90 clockwise and 135 anticlockwise: 90 + 90 = 180, then 180 - 135 = 45, so north-east.

## 8. Ranking and ordering

| Quantity | Formula |
|---|---|
| Total in a row | rank from left + rank from right - 1 |
| Rank from other end | total - rank + 1 |
| People between two | difference of positions - 1 |
| After exchange | the new position equals the other person's old position |

- For comparisons (taller, heavier), arrange all given relations in one line with > signs and read off the required rank.
- Example: 7th from the left and 12th from the right gives 7 + 12 - 1 = 18 in the row.

## 9. Statement questions

- Conclusion: accept only what is directly implied. Reject extremes (all, never, certainly) and causes not mentioned.
- Argument: strong if it is relevant, specific and gives a practical reason; weak if it is vague, personal, emotional or compares with other places. Use "Should" statements for these.
- Course of action: accept constructive, proportionate steps aimed at the problem; reject extreme steps (ban, close, punish everyone).
- When both courses are sensible, "Both follow" is correct. When both are extreme, "Neither follows".

## 10. Venn diagrams and counting

- Two sets: n(A or B) = n(A) + n(B) - n(A and B).
- Three sets: n(A or B or C) = n(A) + n(B) + n(C) - n(A and B) - n(B and C) - n(A and C) + n(all three).
- Relationship diagrams: whole and part gives a circle inside a circle; unrelated classes give separate circles; partly common classes give overlapping circles.
- Example: Doctors, Surgeons, Teachers gives a Surgeons circle inside Doctors, and a separate Teachers circle.

## 11. Mathematical operations

- Step 1: write the substitution table. Step 2: replace every symbol. Step 3: apply BODMAS.
- Example: if + means x, x means -, - means / and / means +, then 12 + 3 x 5 - 5 / 4 becomes 12 x 3 - 5 / 5 + 4 = 36 - 1 + 4 = 39.
- For number-pattern questions, test the same rule on every given row before using it.
- "Choose the correct signs" questions: try the most likely combination first, then verify with BODMAS.

## 12. Clock and calendar

| Fact | Formula or value |
|---|---|
| Angle at H hours M minutes | \|30H - 5.5M\| (if more than 180, subtract from 360) |
| Hands coincide | M = 60H / 11 minutes past H; 11 times in 12 hours |
| Hands opposite / at right angles | opposite 11 times and at right angles 22 times in 12 hours |
| Ordinary year | 1 odd day |
| Leap year | 2 odd days |
| 100 / 200 / 300 / 400 years | 5 / 3 / 1 / 0 odd days |

- Day code: Sunday 0, Monday 1, ... Saturday 6.
- Leap year: divisible by 4; a century year only if divisible by 400 (so 2100 is not a leap year).
- Example: angle at 2:20 = |60 - 110| = 50 degrees.
- Example: 26 January 1950. Years before: 1600 gives 0, 300 gives 1, 49 years give 49 + 12 = 61 = 5 odd days. Total 6. Days in 1950 up to 26 January leave 26 = 5. Sum 11 gives 4, which is Thursday.

## 13. Alphabet test

- Position from left + position from right = 27.
- "Nth to the right of the Mth letter" is M + N; to the left is M - N.
- Alphabetical rearrangement questions: write the sorted word and compare position by position.
- Example: the 8th letter from the left is H, the 8th from the right is S (19th); letters between = 19 - 8 - 1 = 10.

## 14. Frequently asked in DSSSB

- Letter series and number series (often with a missing term in the middle).
- Coding-decoding (letter shift, and "what is the code for ..." from three given sentences).
- Statement and conclusion, statement and argument ("strong" or "weak"), and three-statement syllogisms.
- Seating or ranking puzzles (a row of seven friends facing north).
- Blood relation and direction (right-angle path), plus "mathematical operations" with exchanged signs.
- Odd letter-group or number-pair selection.

## 15. Fifteen quick-revision one-liners

1. Total in a row = left rank + right rank - 1.
2. Rank from the other end = total - rank + 1.
3. Opposite letters add to 27.
4. EJOTY = 5, 10, 15, 20, 25.
5. All + All gives All; All + Some gives nothing.
6. Some + No gives Some not.
7. "Some" and "No" on the same pair means "Either or".
8. Clockwise adds to the heading, anticlockwise subtracts.
9. Morning shadow points west, evening shadow points east.
10. Angle between hands = |30H - 5.5M|.
11. Hands overlap 11 times in 12 hours.
12. 100 years = 5 odd days; 400 years = 0 odd days.
13. Century years need divisibility by 400 to be leap years.
14. n(A or B) = n(A) + n(B) - n(A and B).
15. Check every given row or pair before applying a pattern.

## 16. Five common traps

1. Assuming the diagram from outside knowledge in syllogism ("All cats are dogs" is true for the question).
2. Forgetting that "Some A are B" does not mean "Some A are not B".
3. Mixing up left and right after a turn; always redraw the facing direction.
4. Ranking: forgetting the -1 when adding the left and right ranks.
5. Substitution questions: solving with the original signs, or applying + before x. Always substitute first, then use BODMAS.
