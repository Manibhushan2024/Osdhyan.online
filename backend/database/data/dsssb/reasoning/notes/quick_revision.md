# General Intelligence & Reasoning — Fast Revision Sheet

## How to use this sheet
- Section A has **20 reasoning questions** at 1 mark each. A wrong answer costs **−0.25**, so skip a pure guess, but attempt anything you can narrow to two options. Most DSSSB reasoning questions are easy (40 of the 61 asked in 2023–24) — the marks go to whoever applies a fixed method fastest.
- ⭐ = the same type was asked in the four DSSSB TGT CS papers of 2023–24 (61 real reasoning questions: 24 logic and operations, 15 analogy and odd one out, 14 relations/direction/ranking, 8 series and coding, 0 non-verbal).
- Read order (60–75 min): Top 30 → Logic & Operations (biggest block) → Analogy & Classification → Relations, Direction & Ranking → Series & Coding → Non-verbal → memory hooks → last check.
- Time plan in the exam: 20 questions in about 15 minutes. Do odd-one-out pairs, ranking, sign replacement and statement questions first; leave long seating puzzles and three-statement syllogisms for the end.

| Step | Action |
|---|---|

## Syllogism, Statements, Venn Diagrams & Mathematical Operations

### Syllogism combinations ⭐
| Premises | Conclusion | Example |
|---|---|---|
| All + All | All | All cats are dogs, all dogs are birds → all cats are birds |
| All + No | No | All pencils are pens, no pen is rubber → no pencil is rubber |
| Some + All | Some | Some dogs are goats, all goats are peacocks → some peacocks are dogs ⭐ |
| Some + No | Some … not | Some men are kings, no king is a thief → some men are not thieves |
| No + All | Some (reversed) … not | No flower is stone, all stones are rocks → some rocks are not flowers |
| All + Some | Nothing | All teachers are scholars, some scholars are doctors → nothing about teachers and doctors |
| Some + Some | Nothing | Some C are D, some D are E → nothing ⭐ |
| No + No | Nothing | — |
| Conversions | All A are B → some B are A; No A is B → no B is A; Some → Some; Some-not → none | — |
| Either–or | "Some A are B" / "No A is B" when neither follows alone | Tables–fans case |

### Statement questions ⭐
| Type | Follows | Does not follow |
|---|---|---|
| Conclusion | Direct result, restatement, stated purpose, likely effect | Guessed cause, new facts, extreme words, judgments |
| Course of action | Practical, proportionate, solves or prevents the problem, verifies first | Blanket punishment, escaping, banning for everyone |
| Argument | Relevant, important, general, factual | Opinion, trivial, over-general, speculative |
| Assumption | What the speaker must take for granted | What the speaker merely might believe |

| DSSSB statement ⭐ | Key |
|---|---|
| ABC Corporation planning global expansion | Only II (wants the global market) |
| Raveena goes to gym on father's advice | Only I (father cares) |
| Roads deteriorated | Only II (regular inspection) |
| Bridge collapsed | Only I (rescue) |
| False dowry cases rising | Both (verify; act on false cases) |
| College course without affiliation | Neither argument strong (official key) |
