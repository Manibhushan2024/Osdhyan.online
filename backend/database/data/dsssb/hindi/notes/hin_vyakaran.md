# व्याकरण: संधि, समास, उपसर्ग–प्रत्यय, लिंग–वचन–कारक

**30 सेकंड में**
- हर पेपर में व्याकरण से 3–4 प्रश्न आते हैं; सबसे अधिक **संधि-विच्छेद** ⭐ (भास्कर, मात्रुपदेश, उल्लंघन, प्रमाण, इत्यादि) और **समास** ⭐ (विषधर, यथाशीघ्र, गिरहकट, सेठ-साहूकार)।
- संधि = दो **वर्णों** का मेल (विद्या + आलय); समास = दो **शब्दों** का मेल, बीच के परसर्ग का लोप (राजा का पुत्र → राजपुत्र)।
- स्वर संधि के 5 भेद याद रखने का सूत्र: **दी-गु-वृ-य-अ** (दीर्घ, गुण, वृद्धि, यण, अयादि)।
- विसर्ग के बाद **र** आए तो विसर्ग लुप्त और पहला स्वर दीर्घ: निः + रोग = **नीरोग** ⭐ ("निरोग" अशुद्ध)।
- समास पहचान: पहला पद **अव्यय** → अव्ययीभाव; पहला पद **संख्या** → द्विगु; दोनों पद **प्रधान** → द्वंद्व; **तीसरा अर्थ** → बहुव्रीहि ⭐।
- कारक: **से** साधन हो तो करण ("कानों सुनी" ⭐), अलगाव हो तो अपादान; **को** देने के अर्थ में संप्रदान।
- 'दो लीटर दूध' = **परिमाणवाचक** विशेषण, 'दो लड़के' = संख्यावाचक; 'सुलाना' = प्रेरणार्थक क्रिया।

## 1. संधि ⭐

**परिभाषा**: दो निकटवर्ती वर्णों के मेल से जो विकार (परिवर्तन) होता है, उसे संधि कहते हैं। संधि तोड़ना = **संधि-विच्छेद**।

| भेद | पहचान | उदाहरण |
|---|---|---|
| स्वर संधि | स्वर + स्वर | हिम + आलय = हिमालय |
| व्यंजन संधि | व्यंजन + स्वर / व्यंजन | जगत् + नाथ = जगन्नाथ |
| विसर्ग संधि | विसर्ग (ः) + स्वर / व्यंजन | मनः + रथ = मनोरथ |

### 1.1 स्वर संधि के 5 भेद — नियम

| भेद | नियम | सूत्र-रूप |
|---|---|---|
| दीर्घ | सजातीय स्वर मिलकर दीर्घ | अ/आ + अ/आ = आ; इ/ई + इ/ई = ई; उ/ऊ + उ/ऊ = ऊ |
| गुण | अ/आ के बाद इ, उ, ऋ | + इ/ई = ए; + उ/ऊ = ओ; + ऋ = अर् |
| वृद्धि | अ/आ के बाद ए, ओ | + ए/ऐ = ऐ; + ओ/औ = औ |
| यण | इ, उ, ऋ के बाद भिन्न स्वर | इ/ई → य्; उ/ऊ → व्; ऋ → र् |
| अयादि | ए, ऐ, ओ, औ के बाद कोई स्वर | ए → अय्; ऐ → आय्; ओ → अव्; औ → आव् |

### 1.2 व्यंजन संधि — नियम और 10+ उदाहरण

| नियम | उदाहरण |
|---|---|
| वर्ग का पहला वर्ण + स्वर या घोष वर्ण → उसी वर्ग का तीसरा वर्ण | वाक् + ईश = वागीश; दिक् + अंबर = दिगंबर; जगत् + ईश = जगदीश; षट् + आनन = षडानन |
| वर्ग का पहला वर्ण + न/म → उसी वर्ग का पाँचवाँ वर्ण | जगत् + नाथ = जगन्नाथ; उत् + नति = उन्नति; वाक् + मय = वाङ्मय |
| त्/द् + ल → ल्ल ⭐ | उत् + लास = उल्लास; उत् + लंघन = उल्लंघन ⭐; उत् + लेख = उल्लेख |
| त्/द् + च/छ → च्च/च्छ; + ज → ज्ज | उत् + चारण = उच्चारण; सत् + जन = सज्जन |
| त् + श → च्छ; त् + ह → द्ध | उत् + श्वास = उच्छ्वास; उत् + हार = उद्धार |
| म् + व्यंजन → अनुस्वार | सम् + सार = संसार; सम् + कल्प = संकल्प |
| स्वर के बाद छ → च्छ | वि + छेद = विच्छेद; परि + छेद = परिच्छेद |
| ऋ, र, ष के बाद न → ण (णत्व) ⭐ | प्र + मान = प्रमाण ⭐; परि + नाम = परिणाम; राम + अयन = रामायण |
| सम् + कृ → स् का आगम | सम् + कृत = संस्कृत; सम् + कार = संस्कार |

### 1.3 विसर्ग संधि — नियम और 10+ उदाहरण ⭐

| नियम | उदाहरण |
|---|---|
| अः + घोष व्यंजन / अ → ओ | मनः + रथ = मनोरथ; यशः + दा = यशोदा; मनः + योग = मनोयोग; मनः + अनुकूल = मनोनुकूल |
| विसर्ग + च/छ → श् | निः + चल = निश्चल; निः + छल = निश्छल |
| विसर्ग + त/थ → स्; कुछ शब्दों में क/प से पहले भी स् | नमः + ते = नमस्ते; नमः + कार = नमस्कार; भाः + कर = भास्कर ⭐ |
| इः/उः + घोष वर्ण → र् | निः + धन = निर्धन; दुः + गम = दुर्गम; निः + आशा = निराशा |
| इः/उः + क/प → ष् | निः + पाप = निष्पाप; दुः + कर्म = दुष्कर्म |
| विसर्ग + र → विसर्ग लोप, पूर्व स्वर दीर्घ ⭐ | निः + रोग = नीरोग ⭐; निः + रस = नीरस; निः + रव = नीरव |
| अपवाद: पुनः, अंतः → र् | पुनः + जन्म = पुनर्जन्म; अंतः + राष्ट्रीय = अंतरराष्ट्रीय |
| विसर्ग + क/प (अधिकतर) → कोई परिवर्तन नहीं | प्रातः + काल = प्रातःकाल; अंतः + करण = अंतःकरण |


### 1.4 संधि-विच्छेद हल करने की विधि
1. शब्द में **जोड़ का स्थान** खोजें — जहाँ मात्रा बदली हो (ए, ओ, ऐ, औ, य्, व्, र्) या कोई वर्ण दोहरा हो (ल्ल, न्न, च्च)।
2. बदली हुई मात्रा से **उलटा नियम** लगाएँ: 'ए' दिखे तो अ + इ (गुण); 'य' + स्वर दिखे तो इ + भिन्न स्वर (यण); 'अय/आय/अव/आव' दिखे तो ए/ऐ/ओ/औ (अयादि)।
3. विच्छेद के **दोनों खंड सार्थक** होने चाहिए — 'विद + आलय' या 'भास्क + र' जैसे खंड अर्थहीन हैं, इसलिए ऐसे विकल्प तुरंत काटें।
4. विसर्ग वाले शब्दों (मनः, निः, दुः, नमः, भाः, यशः) को पहचानें — यदि मूल शब्द विसर्गांत है तो विच्छेद में विसर्ग अवश्य लिखा जाएगा।

## 2. समास ⭐

**परिभाषा**: दो या अधिक शब्दों के मेल से बना नया छोटा शब्द **समस्त पद** कहलाता है; उसे तोड़ना **समास-विग्रह**। पहला पद **पूर्वपद**, दूसरा **उत्तरपद**।

| समास | प्रधान पद | पहचान | उदाहरण (विग्रह) |
|---|---|---|---|
| अव्ययीभाव ⭐ | पूर्वपद (अव्यय) | पहला पद यथा, प्रति, आ, भर, बे, नि आदि; पूरा पद क्रियाविशेषण | यथाशीघ्र ⭐ (जितना शीघ्र हो), यथाशक्ति, प्रतिदिन, आजन्म, भरपेट, बेखटके |
| तत्पुरुष | उत्तरपद | बीच का कारक-चिह्न लुप्त | राजपुत्र (राजा का पुत्र) |
| कर्मधारय | उत्तरपद | विशेषण–विशेष्य या उपमान–उपमेय | नीलकमल (नीला है जो कमल), चंद्रमुख (चंद्र के समान मुख), महापुरुष |
| द्विगु | उत्तरपद | पहला पद संख्यावाचक, समूह का बोध | त्रिभुवन, चौराहा, नवरात्र, सप्ताह, पंचवटी |
| द्वंद्व ⭐ | दोनों पद | बीच में 'और', 'या', 'आदि'; प्रायः योजक-चिह्न | माता-पिता, राम-लक्ष्मण |
| बहुव्रीहि ⭐ | कोई नहीं (अन्य पद) | दोनों पद मिलकर तीसरे का बोध | विषधर ⭐ (विष को धारण करता है जो — साँप), दशानन (रावण), लंबोदर (गणेश), नीलकंठ (शिव) |

**तत्पुरुष के उपभेद (लुप्त कारक-चिह्न से)**

| उपभेद | लुप्त चिह्न | उदाहरण |
|---|---|---|
| कर्म तत्पुरुष ⭐ | को | गिरहकट ⭐ (गिरह को काटनेवाला), शरणागत, स्वर्गप्राप्त, मनोहर |
| करण तत्पुरुष | से / के द्वारा | हस्तलिखित (हाथ से लिखित), तुलसीकृत, रेखांकित, शोकाकुल |
| संप्रदान तत्पुरुष | के लिए | रसोईघर (रसोई के लिए घर), देशभक्ति, गौशाला, विद्यालय |
| अपादान तत्पुरुष | से (अलग होना) | देशनिकाला (देश से निकाला), पथभ्रष्ट, जन्मांध, ऋणमुक्त |
| संबंध तत्पुरुष | का, के, की | राजपुत्र, गंगाजल, राजमहल, सेनापति |
| अधिकरण तत्पुरुष | में, पर | वनवास (वन में वास), आपबीती, घुड़सवार (घोड़े पर सवार), शोकमग्न |
| नञ् तत्पुरुष | नहीं (अ/अन) | अधर्म, अनाथ, अनपढ़, अज्ञान |

**द्वंद्व के तीन रूप** ⭐

| रूप | पहचान | उदाहरण |
|---|---|---|
| इतरेतर | 'और' से जुड़े, दोनों अलग-अलग | माता-पिता, राम-लक्ष्मण, स्त्री-पुरुष |
| समाहार ⭐ | दोनों के साथ उसी प्रकार की अन्य वस्तुओं का भी बोध | सेठ-साहूकार ⭐, दाल-रोटी, रुपया-पैसा, हाथ-पाँव |
| वैकल्पिक | 'या' से जुड़े, प्रायः विपरीतार्थक | भला-बुरा, पाप-पुण्य, थोड़ा-बहुत |

|---|---|---|
| पीतांबर | पीला है जो अंबर (पीला वस्त्र) | पीत है अंबर जिसका — श्रीकृष्ण |
| नीलकंठ | नीला है जो कंठ | नीला है कंठ जिसका — शिव |
| चतुर्भुज | चार भुजाओं का समूह (द्विगु) | चार हैं भुजाएँ जिसकी — विष्णु |
| दशानन | दस आननों का समूह (द्विगु) | दस हैं आनन जिसके — रावण |

**संधि और समास का अंतर**: संधि में वर्णों का मेल और ध्वनि-परिवर्तन होता है (विद्या + आलय); समास में शब्दों का मेल और परसर्ग का लोप होता है (विद्या के लिए आलय → विद्यालय, संप्रदान तत्पुरुष)। एक ही शब्द में दोनों हो सकते हैं।


**समास पहचानने की विधि**: पहले विग्रह कीजिए। (1) यदि पहला पद अव्यय है और पूरा शब्द क्रिया की विशेषता बताता है तो अव्ययीभाव। (2) यदि विग्रह में कोई कारक-चिह्न (को, से, के लिए, का, में) आता है तो तत्पुरुष। (3) यदि 'है जो' या 'के समान' आता है तो कर्मधारय। (4) यदि पहला पद संख्या है और समूह का बोध होता है तो द्विगु। (5) यदि 'और', 'या', 'आदि' आता है तो द्वंद्व। (6) यदि 'है जिसका / जिसकी / जो' के साथ कोई तीसरा व्यक्ति या वस्तु सामने आती है तो बहुव्रीहि। परीक्षा में विग्रह दिया हो तो उत्तर विग्रह के अनुसार ही दें।

## 7. कारक ⭐

| कारक | विभक्ति (परसर्ग) | पहचान | उदाहरण |
|---|---|---|---|
| कर्ता | ने / शून्य | क्रिया करने वाला | राम **ने** पत्र लिखा |
| कर्म | को / शून्य | जिस पर क्रिया का फल पड़े | मोहन **को** बुलाओ |
| करण ⭐ | से, के द्वारा | क्रिया का **साधन** | कलम **से** लिखो; **कानों** सुनी बात ⭐ |
| संप्रदान | को, के लिए | जिसके लिए / जिसे **दिया** जाए | गरीबों **को** कंबल दो |
| अपादान | से | **अलग होना**, डरना, तुलना | पेड़ **से** पत्ता गिरा |
| संबंध ⭐ | का, के, की; रा, रे, री | दो संज्ञाओं का संबंध | मिठाई **के** डब्बे में से ⭐ |
| अधिकरण | में, पर | क्रिया का **आधार** | मेज़ **पर** पुस्तक है |
| संबोधन | हे, अरे, अजी | पुकारना | **हे** प्रभु! |

**ध्यान रखें**: संबंध कारक के परसर्ग अगली संज्ञा के लिंग–वचन से बदलते हैं — 'डब्बा' पुल्लिंग है और 'में' से पहले तिर्यक रूप 'डब्बे' है, इसलिए 'मिठाई **के** डब्बे में' ⭐।


**'ने' का नियम**: सकर्मक क्रिया भूतकाल में हो तो कर्ता के साथ 'ने' आता है और क्रिया कर्म के लिंग–वचन के अनुसार बदलती है — 'राम ने रोटी खाई' (रोटी स्त्रीलिंग), 'सीता ने गीत गाया' (गीत पुल्लिंग)। अकर्मक क्रिया (आना, जाना, सोना) और 'चुकना', 'सकना', 'लगना' वाली संयुक्त क्रियाओं के साथ 'ने' नहीं आता — 'मैं पुस्तक पढ़ चुका हूँ', 'मैंने पढ़ चुका' अशुद्ध है। जहाँ कर्म के साथ 'को' लगा हो, वहाँ क्रिया सदा पुल्लिंग एकवचन रहती है — 'माँ ने बेटी को बुलाया'।

## 8. संज्ञा, सर्वनाम, विशेषण, क्रिया ⭐

| शब्द-भेद | भेद | उदाहरण |
|---|---|---|
| संज्ञा ⭐ | व्यक्तिवाचक, जातिवाचक, भाववाचक, समूहवाचक, द्रव्यवाचक | दिल्ली; नदी; प्यार ⭐, बुढ़ापा, मिठास; सेना, कक्षा; सोना, दूध |
| सर्वनाम | पुरुषवाचक, निजवाचक, निश्चयवाचक, अनिश्चयवाचक, संबंधवाचक, प्रश्नवाचक | मैं, तुम, आप (आदर); अपने-आप, स्वयं; यह, वह; कोई, कुछ; जो–सो; कौन, क्या |
| विशेषण ⭐ | गुणवाचक, संख्यावाचक, परिमाणवाचक, सार्वनामिक | फटे-पुराने ⭐; तीनों लोक ⭐, दो लड़के; दो लीटर दूध; यह पुस्तक |
| क्रिया ⭐ | अकर्मक, सकर्मक, प्रेरणार्थक, संयुक्त, नामधातु, पूर्वकालिक | हँसना; लिखना; सुलाना, पढ़वाना; पढ़ चुका; अपनाना, शरमाना; खाकर |

- **प्रविशेषण**: विशेषण की विशेषता बताए — 'बहुत सुंदर', 'अत्यंत तेज़'।
- **विशेष्य**: जिसकी विशेषता बताई जाए — 'फटे-पुराने **चिथड़े**'।
- सकर्मक की पहचान: क्रिया से 'क्या' या 'किसे' पूछने पर उत्तर मिले — 'वह **पुस्तक** पढ़ता है'।
- दाँतों के लिए उचित क्रिया 'कटकटाना' ⭐ — शब्द-चयन प्रश्नों में अर्थ से क्रिया चुनें।

## परीक्षा में फँसाने वाले प्रश्न
1. 'भास्कर' का विच्छेद **भाः + कर** ⭐ है, 'भास् + कर' नहीं — विसर्ग ही 'स्' बना है।
2. 'मात्रुपदेश' = **मातृ + उपदेश** (यण) ⭐ — 'मात्र + उपदेश' नहीं; ऋ का र् हुआ है।
3. 'नीरोग', 'नीरस', 'नीरव' शुद्ध हैं; 'निरोग' अशुद्ध ⭐ — विसर्ग + र में पूर्व स्वर दीर्घ।
4. 'प्रमाण' = **प्र + मान** ⭐ — 'ण' णत्व-नियम से बना है, 'माण' कोई शब्द नहीं।
5. 'विषधर', 'दशानन', 'लंबोदर' बहुव्रीहि हैं ⭐ — संख्या (दश) देखकर द्विगु न चुनें; तीसरा अर्थ (साँप, रावण, गणेश) है।
6. 'सेठ-साहूकार' समाहार द्वंद्व ⭐, 'स्त्री-पुरुष' इतरेतर — 'आदि' का भाव हो तो समाहार।
7. 'से' हमेशा करण नहीं — अलगाव हो (पेड़ से गिरा) तो अपादान; 'को' हमेशा कर्म नहीं — देने के अर्थ में संप्रदान।
8. 'दो लीटर दूध' में परिमाणवाचक, संख्यावाचक नहीं; 'आप' आदर में पुरुषवाचक, 'अपने-आप' निजवाचक।

## एक पंक्ति में पुनरावृत्ति
1. संधि = वर्णों का मेल; समास = शब्दों का मेल।
2. स्वर संधि के 5 भेद: दीर्घ, गुण, वृद्धि, यण, अयादि।
3. विद्यालय = विद्या + आलय — दीर्घ संधि।
4. सूर्योदय = सूर्य + उदय — गुण संधि।
5. महर्षि = महा + ऋषि — गुण संधि (आ + ऋ = अर्)।
6. एकैक, सदैव — वृद्धि संधि।
7. इत्यादि = इति + आदि — यण संधि ⭐।
8. मात्रुपदेश = मातृ + उपदेश — यण संधि ⭐।
9. नयन = ने + अन; पवन = पो + अन — अयादि संधि।
10. जगन्नाथ = जगत् + नाथ — व्यंजन संधि।
11. उल्लंघन = उत् + लंघन ⭐; उल्लेख = उत् + लेख।
12. उच्चारण = उत् + चारण; सज्जन = सत् + जन।
13. प्रमाण = प्र + मान ⭐; परिणाम = परि + नाम (णत्व)।
14. संस्कृत = सम् + कृत (स् का आगम)।
15. मनोरथ = मनः + रथ — विसर्ग संधि।
16. भास्कर = भाः + कर ⭐; नमस्कार = नमः + कार।
17. निश्चल = निः + चल; निर्धन = निः + धन।
18. नीरोग = निः + रोग ⭐; नीरस = निः + रस।
19. पुनर्जन्म = पुनः + जन्म (र् वाला अपवाद)।
20. समास के 6 भेद: अव्ययीभाव, तत्पुरुष, कर्मधारय, द्विगु, द्वंद्व, बहुव्रीहि।
21. यथाशीघ्र, यथाशक्ति, आजन्म — अव्ययीभाव ⭐।
22. गिरहकट = गिरह को काटनेवाला — कर्म तत्पुरुष ⭐।
23. हस्तलिखित = हाथ से लिखित — करण तत्पुरुष।
24. रसोईघर = रसोई के लिए घर — संप्रदान तत्पुरुष।
25. देशनिकाला = देश से निकाला — अपादान तत्पुरुष।
26. वनवास = वन में वास — अधिकरण तत्पुरुष।
27. नीलकमल, चंद्रमुख — कर्मधारय।
28. त्रिभुवन, चौराहा, नवरात्र — द्विगु।
29. माता-पिता — इतरेतर द्वंद्व; दाल-रोटी — समाहार द्वंद्व ⭐।
30. विषधर, पीतांबर (श्रीकृष्ण), नीलकंठ (शिव) — बहुव्रीहि ⭐।
31. निरभिमान में दो उपसर्ग: निर् + अभि।
32. बेईमान में 'बे' उर्दू–फ़ारसी उपसर्ग।
33. भुलक्कड़ = भूल + अक्कड़ (कृत् प्रत्यय)।
34. मानवता में 'ता' — तद्धित प्रत्यय।
35. ऐतिहासिक = इतिहास + इक (पहले स्वर की वृद्धि)।
36. विद्वान → विदुषी; कवि → कवयित्री।
37. दही, पानी, मोती पुल्लिंग; आत्मा, आयु, चाय स्त्रीलिंग।
38. प्राण, दर्शन, हस्ताक्षर सदा बहुवचन।
39. 'कानों सुनी बात' — करण कारक ⭐।
40. 'सुलाना' प्रेरणार्थक क्रिया; 'बुढ़ापा' भाववाचक संज्ञा।

## त्वरित आत्म-जाँच
1. 'भास्कर' का संधि-विच्छेद? — **भाः + कर (विसर्ग संधि)।**
2. 'उल्लंघन' का संधि-विच्छेद? — **उत् + लंघन (व्यंजन संधि)।**
3. 'इत्यादि' में कौन-सी संधि? — **यण संधि (इति + आदि)।**
4. 'निरोग' और 'नीरोग' में शुद्ध कौन? — **नीरोग।**
5. 'यथाशीघ्र' में समास? — **अव्ययीभाव।**
6. 'विषधर' में समास? — **बहुव्रीहि (साँप)।**
7. 'सेठ-साहूकार' किस द्वंद्व का उदाहरण है? — **समाहार द्वंद्व।**
8. 'कानों सुनी बात' में 'कानों' कौन-सा कारक? — **करण कारक।**
9. 'दो लीटर दूध' में विशेषण का भेद? — **परिमाणवाचक।**
10. 'अभ्यागत' में कौन-से उपसर्ग हैं? — **अभि + आ।**
