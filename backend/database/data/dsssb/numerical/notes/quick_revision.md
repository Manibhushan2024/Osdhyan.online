# Arithmetical & Numerical Ability — Fast Revision Sheet

## How to use this sheet
- Section A has **20 numerical questions** at 1 mark each; a wrong answer costs **−0.25**. A numerical question can always be checked, so attempt it if you can finish it in about 60–75 seconds; skip one that needs a page of working and come back to it.
- ⭐ = the pattern was asked in the four DSSSB TGT CS papers of 2023–24 (76 real numerical questions). Their split: **percentage, ratio, P&L, interest 35 · time, work, distance, mixtures 16 · number system & simplification 10 · geometry & mensuration 10 · data interpretation 3 · algebra 2 · trigonometry 0 · statistics 0**.
- Read order (45–60 min): Top 30 patterns → percentage/P&L/interest formulas → time–distance formulas → number system → mensuration → algebra and trigonometry → DI and statistics → tables (squares, cubes, fractions) → memory hooks → one-word answers.
- Method for every question: **write the unknown, write one equation, plug in options if the equation is ugly**. Options are often designed so that one of them fits exactly.

## 2. Percentage, ratio, average, ages, profit–loss, SI–CI

### Percentage
| Rule | Formula |
|---|---|
| % change | (new − old)/old × 100 |
| r% more → other is less by | r/(100 + r) × 100 ⭐ |
| r% less → other is more by | r/(100 − r) × 100 |
| Successive a%, b% | a + b + ab/100 ⭐ |
| Price ↑ r%, same spending | Consumption ↓ r/(100 + r) × 100 |
| Growth / depreciation | P(1 ± r/100)^n ⭐ |
| Two candidates, winner w%, margin M | Total = M ÷ (2w − 100)% |

### Ratio, variation, partnership
| Rule | Formula |
|---|---|
| Mean proportional | √(ab) |
| Third / fourth proportional | b²/a; bc/a |
| A : B and B : C | Equalise B |
| Fractional ratio | Multiply by the LCM of the denominators ⭐ |
| Variation | A = kB/C — find k from the first case ⭐ |
| Partnership | Profit ∝ Σ capital × months ⭐ |
| Incomes a : b, expenses c : d, equal savings S | Solve ax − cy = S, bx − dy = S |

### Average and ages
| Rule | Formula |
|---|---|
| Correct average | old + (correct − wrong)/n ⭐ |
| New member raises average by d | old average + (n + 1)d |
| Replacement raises average by d | replaced + n × d |
| Consecutive numbers | average = middle |
| Overlapping groups | shared item = sum of group totals − overall total |
| Ages | difference constant; part-difference = age gap ⭐ |

### Profit, loss, discount
| Rule | Formula |
|---|---|
| Profit % | (SP − CP)/CP × 100 (on CP) |
| Discount % | (MP − SP)/MP × 100 (on MP) |
| Mark-up m, discount d | profit = m − d − md/100 ⭐ |
| MP/CP | (100 + P)/(100 − d) |
| Successive discounts | multiply (1 − d/100) factors ⭐ |
| Same SP, ±r% | loss r²/100 % |
| CP of x = SP of y | profit (x − y)/y × 100 |
| False weight | (true − false)/false × 100 |
| SP₁ at l% loss → SP₂ at g% gain | SP₁ × (100 + g)/(100 − l) ⭐ |

### Simple and compound interest
| Rule | Formula |
|---|---|
| SI | PRT/100 |
| Amount | P(1 + RT/100) |
| Two amounts ⭐ | SI/yr = (A₂ − A₁)/(T₂ − T₁) |
| Doubles in T years | R = 100/T; n times → R = (n − 1)100/T |
| Different rates ⭐ | SI = P(R₁T₁ + R₂T₂)/100 |
| CI amount | P(1 + R/100)^n ⭐ |
| Half-yearly / quarterly | R/2, 2n / R/4, 4n ⭐ |
| CI − SI (2 years) | P(R/100)² ⭐ |
| CI − SI (3 years) | P(R/100)²(3 + R/100) |
| SI & CI of 2 years | R = 2(CI − SI)/SI × 100 ⭐ |
| Two equal instalments | X = P(1 + r)²/(2 + r) (r as a decimal) ⭐ |
| Effective rates | 10%: 21% (2 y), 33.1% (3 y); 20%: 44% (2 y), 72.8% (3 y) |

## 9. Fifteen memory hooks
1. **"Of before over"** — "of" is done before ÷ ⭐.
2. **"Gap is gospel"** — the difference of two ages never changes ⭐.
3. **"Differences decide the divisor"** — same remainder → HCF of differences ⭐.
4. **"LCM plus leftover"** — same remainder r → LCM + r ⭐.
5. **"Than is the base"** — in "% more/less than Y", divide by Y ⭐.
6. **"Times more adds one"** — 8 times more = 9 times as much ⭐.
7. **"Multiply, never add"** — successive changes and discounts multiply ⭐.
8. **"Profit on cost, discount on marked"** ⭐.
9. **"Total over total"** — average speed and overall % are totals divided by totals ⭐.
10. **"Train eats the platform"** — add the platform's length to the train's ⭐.
11. **"Down adds, up subtracts"** — boat + stream downstream, boat − stream upstream ⭐.
12. **"Melt keeps the metal"** — volume is conserved, surface is not ⭐.
13. **"Slant for surface, height for volume"** — cone CSA uses l, volume uses h ⭐.
14. **"Square for area, cube for volume"** — scale factor k → k², k³ ⭐.
15. **"Some People Have Curly Brown Hair, Through Proper Brushing"** — sin = P/H, cos = B/H, tan = P/B.

## 11. Exam-day checklist
- Units first: m vs km, s vs h, cm vs m, lakh vs crore ⭐.
- "Approximately / correct to one decimal": carry one extra decimal before choosing ⭐.
- Mixed numbers and recurring decimals → improper fractions before any operation ⭐.
- For any equation of degree 2 (usual speed, ages, CI rate), **test the options** — it is faster than solving ⭐.
- In percent questions choose 100 as the base; in work and pipes choose the LCM as the total.
- After answering, check one condition from the question with your answer (e.g. the remainder really is the same; the ratio really becomes 4 : 5).
- Leave a question if you cannot see the first step in 20 seconds; return at the end.
- Negative marking: 4 wrong guesses cancel 1 correct answer — guess only after eliminating two options.
