# Algebra & Trigonometry Basics

**In 30 seconds**
- In the 2023–24 DSSSB TGT CS papers only **2** questions came from here, both **surds** ⭐: x = √(19 + 4√15) − √(19 − 4√15) and √(23 + 6√10) − √(23 − 6√10). Trigonometry was not asked in those four papers, but it is in the syllabus — learn the standard values, three identities and heights & distances.
- √(a + 2√b) = √m + √n where **m + n = a and mn = b** ⭐; write 4√15 as 2√60 or as 2 × 2 × √15.
- x + 1/x = k → x² + 1/x² = k² − 2; x³ + 1/x³ = k³ − 3k.
- a + b + c = 0 → a³ + b³ + c³ = 3abc.
- Quadratic ax² + bx + c = 0: sum of roots −b/a, product c/a, equal roots when b² − 4ac = 0.
- Remainder when p(x) is divided by (x − a) is p(a).
- sin²θ + cos²θ = 1; sec²θ − tan²θ = 1; cosec²θ − cot²θ = 1. sin A = cos B with both acute → A + B = 90°.
- Heights & distances: tan θ = height ÷ base; 30° ↔ 1/√3, 45° ↔ 1, 60° ↔ √3.

## 1. Algebraic identities

| Identity | Formula |
|---|---|
| Square of a sum | (a + b)² = a² + 2ab + b² |
| Square of a difference | (a − b)² = a² − 2ab + b² |
| Sum and difference | (a + b)² − (a − b)² = 4ab; (a + b)² + (a − b)² = 2(a² + b²) |
| Difference of squares | a² − b² = (a + b)(a − b) |
| Cube of a sum | (a + b)³ = a³ + b³ + 3ab(a + b) |
| Cube of a difference | (a − b)³ = a³ − b³ − 3ab(a − b) |
| Sum of cubes | a³ + b³ = (a + b)(a² − ab + b²) = (a + b)³ − 3ab(a + b) |
| Difference of cubes | a³ − b³ = (a − b)(a² + ab + b²) = (a − b)³ + 3ab(a − b) |
| Three terms | (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) |
| Three cubes | a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) |
| Special case | If a + b + c = 0 then a³ + b³ + c³ = 3abc |

**Worked example.** a + b = 10, ab = 21. a² + b² = 100 − 42 = **58**.
**Shortcut:** guess the numbers (7 and 3) and check: 49 + 9 = 58.

**Worked example.** a + b = 7, ab = 10. a³ + b³ = 343 − 3 × 10 × 7 = **133** (a = 5, b = 2: 125 + 8).

**Worked example.** a − b = 3, a³ − b³ = 117. 117 = 27 + 9ab → **ab = 10**.

**Worked example.** a + b + c = 0, abc = 4 → a³ + b³ + c³ = **12**.
**Shortcut:** put simple values satisfying the condition (a = 1, b = 1, c = −2 gives 1 + 1 − 8 = −6 = 3 × (−2) ✓) to test any "a + b + c = 0" identity.

**Worked example.** 103 × 97 = 100² − 3² = **9991**.

**Worked example.** If a² + b² + c² = ab + bc + ca (real numbers) then a = b = c, because 2(a² + b² + c² − ab − bc − ca) = (a − b)² + (b − c)² + (c − a)² = 0.

## 2. The x + 1/x family

| Given | Result |
|---|---|
| x + 1/x = k | x² + 1/x² = k² − 2 |
| x + 1/x = k | x³ + 1/x³ = k³ − 3k |
| x − 1/x = k | x² + 1/x² = k² + 2 |
| x − 1/x = k | x³ − 1/x³ = k³ + 3k |
| x² + 1/x² = m | x⁴ + 1/x⁴ = m² − 2 |
| x + 1/x = 2 | x = 1, so every power sum = 2 |
| x + 1/x = −2 | x = −1 |
| x + 1/x = 1 | x³ = −1, so x³ + 1/x³ = −2 |

**Worked example.** x + 1/x = 5 → x² + 1/x² = **23**.
**Worked example.** x + 1/x = 3 → x³ + 1/x³ = 27 − 9 = **18**.
**Worked example.** x − 1/x = 4 → x² + 1/x² = 18 → x⁴ + 1/x⁴ = 324 − 2 = **322**.
**Worked example.** x = 2 + √3 → 1/x = 2 − √3 → x + 1/x = 4 → x² + 1/x² = **14**.
**Shortcut:** for x = a + √b with a² − b = 1, 1/x is just a − √b.

## 3. Surds and indices ⭐

| Rule | Formula |
|---|---|
| Product | √a × √b = √(ab) |
| Quotient | √a/√b = √(a/b) |
| Rationalise 1/(√a − √b) | (√a + √b)/(a − b) |
| Square-root of a ± 2√b ⭐ | √(a ± 2√b) = √m ± √n with m + n = a, mn = b (m > n) |
| Compare surds | Square them (or raise to the LCM of the root orders) |
| Indices | a^m × a^n = a^(m+n); (a^m)^n = a^(mn); a^0 = 1; a^(−n) = 1/a^n; a^(1/n) = ⁿ√a |

**Worked example ⭐ (DSSSB, June 2023).** x = √(19 + 4√15) − √(19 − 4√15).
4√15 = 2√60 → m + n = 19, mn = 60 → 15 and 4 → √(19 + 4√15) = √15 + 2, √(19 − 4√15) = √15 − 2. x = **4**.
**Shortcut:** in "√(a + 2√b) − √(a − 2√b)" the answer is 2√n (twice the smaller root); in "+" form it is 2√m.

**Worked example ⭐ (DSSSB, June 2023).** x = √(23 + 6√10) − √(23 − 6√10) lies between?
6√10 = 2√90 → m + n = 23, mn = 90 → 18 and 5 → x = 2√5 ≈ 4.47 → **between 4 and 4.5**.
**Shortcut:** square the answer to check: x² = 2a − 2√(a² − 4b) = 46 − 2√(529 − 360) = 46 − 26 = 20 → x = √20.

**Worked example.** √(11 + 2√30) − √(11 − 2√30): 6 + 5 = 11, 6 × 5 = 30 → (√6 + √5) − (√6 − √5) = **2√5**.

**Worked example.** √(14 + 6√5) + √(14 − 6√5): 6√5 = 2 × 3√5 = 2√45 → 9 + 5 = 14, 9 × 5 = 45 → (3 + √5) + (3 − √5) = **6**.

**Worked example.** 1/(√7 − √6) − 1/(√6 − √5) = (√7 + √6) − (√6 + √5) = **√7 − √5**.
**Shortcut:** when the two surds differ by 1 under the root, 1/(√(n + 1) − √n) = √(n + 1) + √n.

**Worked example.** Which is larger, √3 or ∛5? Raise to the 6th power: 3³ = 27, 5² = 25 → **√3** is larger.

**Worked example.** (27)^(2/3) × (16)^(−1/4) = 9 × 1/2 = **4.5**.

## 4. Linear equations

| Situation | Method |
|---|---|
| Two equations, two unknowns | Substitution or elimination |
| Sum S and difference D of two numbers | Larger = (S + D)/2, smaller = (S − D)/2 |
| a₁x + b₁y = c₁ and a₂x + b₂y = c₂ | Unique if a₁/a₂ ≠ b₁/b₂; none if a₁/a₂ = b₁/b₂ ≠ c₁/c₂; infinite if all three equal |
| Word problems | Let the unknown be x and translate each sentence |

**Worked example.** 2x + 3y = 13 and 3x − y = 3 → y = 3x − 3 → 11x = 22 → x = 2, y = 3 → x + y = **5**.
**Shortcut:** in MCQs, test the options in both equations.

**Worked example.** Sum 75, difference 15 → 45 and 30 → product **1350**.

**Worked example.** For what k does kx + 3y = 5, 6x + 9y = 7 have no solution? k/6 = 3/9 → **k = 2** (and 5/7 ≠ 1/3 ✓).

## 5. Quadratic equations and polynomials

| Fact | Formula |
|---|---|
| Roots | x = [−b ± √(b² − 4ac)]/2a |
| Sum, product | α + β = −b/a; αβ = c/a |
| Discriminant D = b² − 4ac | D > 0 two real roots; D = 0 equal roots; D < 0 no real roots |
| Equation from roots | x² − (sum)x + product = 0 |
| α² + β² | (α + β)² − 2αβ |
| Remainder theorem | p(x) ÷ (x − a) leaves p(a) |
| Factor theorem | (x − a) is a factor if p(a) = 0 |

**Worked example.** 2x² − 7x + 3 = 0 → (2x − 1)(x − 3) = 0 → **x = 3, 1/2**.
**Shortcut:** check the options with sum 7/2 and product 3/2.

**Worked example.** α, β roots of x² − 5x + 6 = 0 → α² + β² = 25 − 12 = **13**.

**Worked example.** x² + kx + 16 = 0 has equal roots → k² = 64 → **k = ±8**.

**Worked example.** Remainder of x³ − 2x² + 4x − 5 ÷ (x − 2) = 8 − 8 + 8 − 5 = **3**.

**Worked example.** If (x + 2) is a factor of x³ + 3x² + kx − 4, find k: p(−2) = −8 + 12 − 2k − 4 = −2k = 0 → **k = 0**.

## 6. Trigonometric ratios

| θ | 0° | 30° | 45° | 60° | 90° |
|---|---|---|---|---|---|
| sin | 0 | 1/2 | 1/√2 | √3/2 | 1 |
| cos | 1 | √3/2 | 1/√2 | 1/2 | 0 |
| tan | 0 | 1/√3 | 1 | √3 | not defined |
| cot | not defined | √3 | 1 | 1/√3 | 0 |
| sec | 1 | 2/√3 | √2 | 2 | not defined |
| cosec | not defined | 2 | √2 | 2/√3 | 1 |

| Ratio | Definition (right triangle) |
|---|---|
| sin θ | Perpendicular/Hypotenuse |
| cos θ | Base/Hypotenuse |
| tan θ | Perpendicular/Base = sin θ/cos θ |
| cosec, sec, cot | Reciprocals of sin, cos, tan |

**Worked example.** sin 30° + cos 60° = 1/2 + 1/2 = **1**; cos 0° + sin 90° + tan 45° = **3**.

**Worked example.** 2 sin²30° + 3 tan²60° − cos²45° = 1/2 + 9 − 1/2 = **9**.
**Shortcut:** memorise sin for 0°, 30°, 45°, 60°, 90° as √0/2, √1/2, √2/2, √3/2, √4/2; cos is the same list reversed.

**Worked example.** tan θ = 3/4 (acute) → sides 3, 4, 5 → sin θ = **3/5**, cos θ = 4/5.
**Shortcut:** Pythagorean triplets 3-4-5, 5-12-13, 8-15-17, 7-24-25 give every ratio from one ratio.

## 7. Identities and complementary angles

| Identity | Formula |
|---|---|
| Pythagorean | sin²θ + cos²θ = 1 |
| | sec²θ − tan²θ = 1 → (sec θ + tan θ)(sec θ − tan θ) = 1 |
| | cosec²θ − cot²θ = 1 → (cosec θ + cot θ)(cosec θ − cot θ) = 1 |
| Complementary | sin(90° − θ) = cos θ; tan(90° − θ) = cot θ; sec(90° − θ) = cosec θ |
| sin A = cos B (acute) | A + B = 90° |
| tan A tan B = 1 | A + B = 90° |

**Worked example.** (1 − sin²θ) sec²θ = cos²θ × 1/cos²θ = **1**.

**Worked example.** sec θ + tan θ = 4 → sec θ − tan θ = **1/4**; adding, sec θ = 17/8, tan θ = 15/8 → sin θ = **15/17**.
**Shortcut:** if sec θ + tan θ = p, then sin θ = (p² − 1)/(p² + 1) = 15/17.

**Worked example.** tan 10° tan 20° tan 70° tan 80° = (tan 10° cot 10°)(tan 20° cot 20°) = **1**.

**Worked example.** sin 3θ = cos(θ − 6°) → 3θ + θ − 6° = 90° → **θ = 24°**.

**Worked example.** sin²25° + sin²65° + tan 30° tan 60° = 1 + 1 = **2**.

**Worked example.** sin θ + cos θ = √2 → 1 + 2 sin θ cos θ = 2 → sin θ cos θ = **1/2** (θ = 45°).
**Shortcut:** when the given value is the maximum possible (√2 for sin + cos), θ = 45°; substitute directly.

## 8. Heights and distances

| Situation | Relation |
|---|---|
| Angle of elevation θ from distance d | Height = d tan θ |
| Angle of depression from height h | Distance = h cot θ (angle of depression = angle of elevation from the other end) |
| Ladder of length L at θ with ground | Height on wall = L sin θ; foot from wall = L cos θ |
| Shadow when the Sun's altitude is θ | Shadow = h cot θ |
| Two positions with angles α and β (same side) | Gap = h(cot α − cot β) |

**Worked example.** From 30 m away the top of a tower is at 60° → height = 30√3 m **(≈ 51.96 m)**.

**Worked example.** From a 60 m building the angle of depression of a car is 30° → distance = 60 cot 30° = **60√3 m**.

**Worked example.** A 20 m ladder at 60° with the ground reaches 20 sin 60° = **10√3 m** up the wall.

**Worked example.** A shadow shortens by 40 m when the Sun's altitude rises from 30° to 60° → h(√3 − 1/√3) = 40 → h × 2/√3 = 40 → **h = 20√3 m**.
**Shortcut:** for 30° → 60°, the gap equals (2/√3) × h, so h = gap × √3/2.

**Worked example.** A kite string of 100 m makes 30° with the ground; height of kite = 100 sin 30° = **50 m**.

## Exam traps
1. x + 1/x = k gives x² + 1/x² = k² − **2**, but x − 1/x = k gives k² + **2**.
2. In √(a + 2√b), b is the number **inside** after writing the coefficient as 2√b: 4√15 = 2√60, not 2√15 ⭐.
3. √(a + 2√b) − √(a − 2√b) = 2√n (smaller part), not 2√m ⭐.
4. Equal roots: k² = 64 gives k = **±8** — do not drop the negative.
5. tan 90° and cot 0° are not defined; they are not 0.
6. Angle of depression from the top equals the angle of elevation from the bottom (alternate angles).
7. sin 2θ ≠ 2 sin θ; check with θ = 30°: sin 60° = 0.866, 2 sin 30° = 1.
8. The remainder theorem uses x = a for divisor (x − a): divisor (x + 2) means put x = −2.
