# English Language & Comprehension — Fast Revision Sheet

## How to use this sheet
- Section A has **20 English questions** at 1 mark each; a wrong answer costs **−0.25**. Skip a pure guess, but attempt anything you can narrow to two options.
- ⭐ = asked in the four DSSSB TGT CS papers of 2023–24 (80 real English questions). The split was about **9 vocabulary + 7 reading (5 RC + 2 para jumbles) + 4 grammar/error questions** per paper.
- Read order (60–75 min): Top 30 → Vocabulary lists (the biggest block) → Error catalogue → Grammar tables → Reading, cloze and para-jumble method → memory hooks → last check.
- Every rule is written as ✔ correct / ✘ wrong, because DSSSB tests grammar through error spotting, fill in the blank and sentence improvement — not through definitions.

## Grammar

### Tenses — signal words

| Signal | Tense | ✔ Example |
|---|---|---|
| *Look! Listen! now, at present* | present continuous | Look! The children **are playing**. |
| *always, usually, every day*; facts | simple present | The sun **rises** in the east. |
| *just, already, yet, ever, never, so far* | present perfect | I **have** just **finished**. |
| *since* + point / *for* + period, still going on | present perfect continuous | She **has been living** here since 2015. |
| *yesterday, ago, last year, in 2010* | simple past | He **left** two hours ago. |
| earlier of two past actions | past perfect | The train **had left** before we reached. |
| *this time tomorrow / next week* | future continuous | We **will be lying** on the beach. |
| *by* + future time | future perfect | I **will have finished** by evening. |
| *Hardly/Scarcely/Barely … when; No sooner … than* | past perfect + inversion ⭐ | **No sooner had** he left **than** it rained. |
| *It is high time* | simple past | It is high time we **left**. |
| *If I* (unreal present) | were | If I **were** you… |
| *If* (unreal past) | had + V3 / would have + V3 | If you **had asked**, I **would have helped**. |
| *If* (real future) | simple present / will | If he **comes**, I **will** tell him. |
| *lest* | should + V1 | …lest you **should** fall. |
| universal truth after past reporting verb | simple present | He said the earth **moves** round the sun. |

**Stative verbs** (know, believe, understand, own, belong, love, hate, prefer, seem, contain) — no continuous: ✘ *I am knowing* → ✔ *I know*.

### Articles

| Rule | ✔ | ✘ |
|---|---|---|
| *an* before a vowel **sound** | an hour, an honest man, an MBA, an MLA | a hour |
| *a* before a consonant sound | a university, a European, a one-day match | an university |
| *the* + rivers, oceans, mountain ranges, deserts, island groups | the Ganga, the Himalayas, the Thar | |
| no article + single peaks, lakes, most countries | Mount Everest, Lake Wular, India | the Mount Everest |
| *the* + superlative, ordinal, unique object, instrument | the best, the first, the sun, play the flute | |
| no article + games, meals, languages, subjects | play cricket, have lunch, speak Hindi | play the cricket |
| place used for its purpose | go to school, in hospital, to bed | go to the school (as student) |
| *What a / many a / such a* + singular noun | What a pity! Many a student | What pity! |

### Subject–verb agreement

| Rule | ✔ |
|---|---|
| each / every / either / neither / everyone + singular | Each of the boys **was** given a prize. |
| many a + singular noun + singular verb | Many a student **has** failed. |
| the number of → singular; a number of → plural | The number of applicants **is** rising. |
| neither…nor / either…or → nearer subject | Neither the manager nor the employees **were** present. |
| as well as / along with / together with → first subject | The Principal, along with the teachers, **is** planning. |
| two nouns as one idea → singular | Bread and butter **is** my breakfast. |
| -ics subjects, news → singular | Mathematics **is** easy. The news **is** good. |
| furniture, luggage, advice, information, scenery, equipment → singular, no plural | The furniture **is** new. |
| police, cattle, people → plural | The police **are** here. |
| amount of distance/time/money → singular | Ten kilometres **is** a long walk. |
| one of the + plural noun + who → plural | one of the boys who **have** won |
| the + adjective (the rich, the poor) → plural | The poor **are** honest. |
| collective noun, members disagree → plural | The jury **were** divided in their opinions. |

### Active and passive

| Active | Passive |
|---|---|
| writes / is writing / has written | is written / is being written / has been written |
| wrote / was writing / had written | was written / was being written / had been written |
| will write / will have written | will be written / will have been written |
| can / must / should write | can / must / should be written |
| Do it at once. | Let it be done at once. |
| Please help me. | You are requested to help me. |
| Who wrote this letter? | By whom was this letter written? |
| Someone has stolen my bicycle. | My bicycle has been stolen. |

### Direct and indirect speech

| Change | Rule |
|---|---|
| Reporting verb | said to → told; question → asked; order → ordered; request → requested; *Let's* → proposed/suggested that … should; exclamation → exclaimed with joy/sorrow |
| Tense (past reporting verb) | am/is → was; are → were; has/have → had; past → had + V3; will → would; can → could; may → might; must → had to |
| No tense change | universal truth, habitual fact, reporting verb in present/future |
| Pronouns | 1st person → as subject of reporting verb; 2nd → as object; 3rd → no change |
| Time/place | now → then; here → there; this → that; today → that day; tomorrow → the next day; yesterday → the previous day; ago → before |
| Questions | statement order, no *that*, no question mark; yes/no → *if/whether* |

| ✔ Indirect | ✘ Common error |
|---|---|
| She asked me where I lived. | She asked me where *did I live*. |
| He told me that he was happy. | He *told that* he was happy. / He *said me*… |
| He requested her to help him. | He said her to help me. |
| The teacher said that the earth moves round the sun. | …the earth *moved*… |
| The captain proposed that they should play carefully. | …said that *let us* play… |

### Question tags ⭐, conjunctions ⭐, adjective vs adverb ⭐

| Rule | ✔ |
|---|---|
| positive → negative tag, same auxiliary | She was wearing a gown, **wasn't she**? ⭐ |
| negative → positive tag | You can't hear the birds, **can you**? ⭐ |
| no auxiliary → do/does/did | They went home, **didn't they**? |
| I am → aren't I | I am right, **aren't I**? |
| Let's → shall we | Let's go, **shall we**? |
| imperative → will you | Shut the door, **will you**? |
| nobody / hardly / never → positive tag; nobody → they | Nobody called, **did they**? |
| though/although — no *but*; whether ≠ contrast | **Though** I disagree, I respect her. ⭐ |
| neither … nor; either … or; not only … but also | **Neither** Ram **nor** Shyam came. |
| unless / until — no *not* after them | **Unless** you work hard, you will fail. |
| action verb + adverb | He chewed **slowly**. ⭐ |
| linking verb (look, smell, taste, feel, seem) + adjective | The rose smells **sweet**. |
| being + adjective | her being **honest** ⭐ |
| very + positive; much + comparative | very good; much better |
| no double comparative | taller (✘ *more taller*) |

### Pronouns and comparison

| Rule | ✔ Correct | ✘ Wrong |
|---|---|---|
| object case after a preposition | between you and **me** | between you and I |
| subject case after *than/as* (verb understood) | taller than **I** (am) | taller than me (exam answer) |
| *one* → *one's* | One must do **one's** duty. | …his duty |
| two people → *each other*; more → *one another* | The two sisters love **each other**. | …one another |
| *who* = subject; *whom* = object | the man **who** called; the man **whom** we met | the man whom called |
| *any other* inside the same group | taller than **any other** boy in his class | taller than any boy in his class |
| compare like with like | better than **that of** Delhi | better than Delhi |
| *fewer* + countable; *less* + uncountable | **fewer** books, **less** sugar | less books |
| *elder* (family, no *than*); *older than* | my **elder** brother; **older than** me | elder than me |
| *enough* after an adjective | **strong enough** | enough strong |
| order of personal pronouns (good news): 2-3-1 | **You, he and I** won. | I, you and he won |

### Word choice in sentence improvement ⭐

| ✘ In the sentence | ✔ Better word | Why |
|---|---|---|
| air travel is **hopping** back to normalcy ⭐ | **limping** | slow, struggling recovery |
| any widespread period of instability ⭐ | **extended** | natural collocation with *period* |
| the **flaming** heat of summer ⭐ | **scorching** | collocation for intense heat |
| The palace is **gearing up for** the festival ⭐ | **No substitution required** | *gear up for* = prepare |
| The doctor **wrote** a strong medicine | **prescribed** | precise verb |
| laid stress **over** discipline | laid stress **on** | fixed preposition |
| There was **strong** rain | **heavy** | collocation |
| a **speedy** train ⭐ | **fast** | collocation |
| I am **utterly** aware ⭐ | **fully** | collocation |

**Collocation pairs**: *make* a mistake/decision/effort/progress/noise; *do* homework/duty/harm/a favour; *take* responsibility/a chance/a decision; *commit* a crime; *deliver/give* a speech; *pay* attention; *heavy* rain/traffic; *strong* tea/wind; *thick* fog.

**Gerund or infinitive**: gerund after *avoid, enjoy, finish, mind, practise, consider, deny, postpone, look forward to, object to, be used to*; infinitive after *want, decide, hope, agree, refuse, promise, plan, expect, afford, manage, learn*.

## Reading comprehension, cloze and para jumbles

### RC in five lines
1. Read the **questions first**, then the passage once.
2. **Fact / word-meaning** first: go back to the exact line; replace the word with each option in that sentence.
3. **Title / main idea**: covers the whole passage; **tone**: from the writer's adjectives and verbs.
4. **NOT / EXCEPT**: tick what is in the text; the leftover is the answer — even if it is true in real life ⭐.
5. **Inference**: supported by a line; reject extremes (*always, never, only, completely*).

| Type of passage | Signs |
|---|---|
| Narrative ⭐ | events in time order, *I/he*, *when I was…* |
| Descriptive ⭐ | pictures a place/person, many adjectives |
| **Expository** ⭐ | explains a topic: causes, effects, remedies, neutral |
| Persuasive | urges action: *we must, should* |
| Argumentative | takes a side, answers the other side |

**Tones**: positive — optimistic, appreciative, laudatory, enthusiastic; neutral — informative, objective, analytical, narrative, descriptive, advisory, didactic; negative — critical, sarcastic, cynical, pessimistic, satirical, nostalgic, melancholic.

**The 2023–24 passages** ⭐: travel and language (tone *narrative and descriptive*, title *Travel and Language*); disappearing bicycle mechanics (*unwelcome disruptor = cyclist*, *unfriendly = inhospitable*, opening = interesting way to introduce the topic, cycling symbolises equality); unhealthy workplace competition (*subtle = implied*, moral = win without defeating anyone, type = expository); India's population explosion (main idea = population explosion and its problems, *adding an Australia every year*, *alleviation ≈ eradicate*, antonym of *extinct* = *prevailing*).

### Cloze in five lines
1. Read the full passage first: topic and tone.
2. Each blank tests **collocation, grammar, preposition, logic or tone**.
3. Remove wrong parts of speech, then broken collocations.
4. Check connectors: *however* reverses, *therefore* concludes, *moreover* adds.
5. Negative adverbs (*seldom, hardly, rarely*) flip the verb that follows: *seldom **miss** their goals*.

**Connectors** — add: moreover, furthermore, besides · contrast: however, yet, although, nevertheless, whereas · cause: because, since, owing to · result: therefore, thus, hence, consequently, as a result · condition: unless, provided that · conclusion: in short, to sum up.

### Para jumbles in seven lines ⭐
1. **Opener**: introduces the topic in full — a name, a definition, *This is the story of…*, *Historically…*, a birth date.
2. **Never first**: a sentence starting with *It, He, They, This, The other, However, As a result, That means, Yet*.
3. **Lock pairs**: pronoun → its noun; *one … the other*; problem → *That means* → *However* → solution; cause → *As a result*.
4. **Time order**: *at first → slowly → within a few years → today*; birth → childhood accident → consequence.
5. **General → specific**: topic → statistic → comment → conclusion.
6. **Closer**: result, solution, moral, *Today…*, *In the last 50 years…*.
7. Check the first letter of each option first; most options fall at once.

## Ten mistakes that cost marks in Section A English
1. **Answering RC from general knowledge.** The passage is the only source; an option that is true in real life but absent from the text is wrong ⭐.
2. **Choosing "No substitution required" by default.** It was right once in 2023–24 (*gearing up for*) ⭐; test every option first.
3. **Reading only the segment, not the sentence.** Agreement errors sit in a segment far from the subject (*The Principal, along with the teachers, are*).
4. **Missing the second spelling error.** Wrong options in spelling-sentence items often have two errors; the right option has none ⭐.
5. **Taking idioms literally.** *Miss the boat*, *face the music* and *break even* have nothing to do with boats, music or breaking ⭐.
6. **Confusing look-alike words.** *Gerontology* vs *genealogy*, *apiary* vs *aviary*, *stationary* vs *stationery*, *elude* vs *allude*.
7. **Putting a pronoun sentence first** in a para jumble ⭐.
8. **Mixing the inversion pairs.** *No sooner … than*; *Hardly/Scarcely/Barely … when* ⭐.
9. **Changing the tense of a universal truth** in indirect speech.
10. **Guessing blindly.** With −0.25 per wrong answer, guess only after cutting the options to two.

## 60-second memory hooks
- **"No sooner THAN, Hardly WHEN"** — *than* has an *n* like *No*; *when* goes with *Hardly/Scarcely/Barely*; all take **had + subject + V3**.
- **"Prefer TO, senior TO"** — every Latin comparative (senior, junior, superior, inferior, prior) takes *to*.
- **"DESPITE has no OF"** — *in spite **of***, *despite* alone.
- **"Since = start, For = length"** — since Monday, for two days.
- **"Each, Every, Either, Neither, Many a = ONE"** — singular verb.
- **"Nearer noun decides"** — neither…nor, either…or, not only…but also.
- **"First noun decides"** — as well as, along with, together with.
- **"If never takes will"** — *If he comes*.
- **"Being + adjective"** — *being honest*, *being kind*.
- **"Action → -ly, Linking → no -ly"** — chewed slowly; smells sweet.
- **"Let's → shall we"**, **"I am → aren't I"**.
- **"StationEry = Envelopes; StationAry = stAnding still."**
- **"PrincipAL is your pAL; principLE is a ruLE."**
- **"Heel is on the foot, heal is what the doctor does."**
- **"Re-FER-red: stress at the end, double the r."**
- **"Geron = old man → gerontology; anthropos = man → anthropology; chronos = time → chronology."**
- **"Apiary — Apis (bee); Aviary — Avis (bird); Arsenal — Arms."**
- **"Expository explains; Persuasive pushes; Narrative narrates."**
- **"NOT question → tick the present, pick the absent."**
- **"Para jumble: Pronoun is never the pioneer."**
