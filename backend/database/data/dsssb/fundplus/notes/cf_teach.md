# Teaching Methodology of Computer Science

**In 30 seconds**
- About 4 questions per paper; the 2023–24 papers asked 40, and most were child development, inclusion and policy, not pure CS pedagogy.
- Piaget is the single most-asked name: stages, conservation, horizontal decalage, play.
- Learner-centred = constructivist = "learning by doing"; subject-centred = confined to the textbook.
- Project method (Kilpatrick): students themselves purpose and plan; heuristic method: H. E. Armstrong.
- Assessment FOR learning = formative (peer, self, teacher feedback); OF = summative; AS = self-reflection.
- Positive reinforcement adds something pleasant (high grades); negative reinforcement removes something unpleasant; both increase behaviour.
- Policy facts: RTE 2009 (6–14, 25% EWS), RPWD 2016 (21 disabilities), ICDS 1975 (under-6), Women's Policy 2001, 71st Amendment (Konkani, Manipuri, Nepali).

## 1. Aims, objectives and curriculum

| Domain of objective | CS example |
|---|---|
| Knowledge | Recall parts of a computer, gate names |
| Understanding | Explain how a loop or a stack works |
| Application | Use a spreadsheet formula to solve a new problem |
| Skill | Type, write and debug code, use the lab safely |
| Attitude / interest | Values cyber-ethics, curiosity, teamwork |

**Bloom's taxonomy**

| Original cognitive (Bloom, 1956; nouns) | Revised (Anderson & Krathwohl, 2001; verbs) | Verbs |
|---|---|---|
| Knowledge | Remember | list, define, recall |
| Comprehension | Understand | explain, classify, summarise |
| Application | Apply | use, implement, solve |
| Analysis | Analyse | compare, debug, differentiate |
| Synthesis (5th) | Evaluate (5th) — originally Evaluation | judge, justify, critique |
| Evaluation (6th, highest) | Create (6th, highest) — originally Synthesis | design, build, compose |

- Revision: Synthesis became **Create** and moved to the top; Evaluation moved to 5th; a knowledge dimension (factual, conceptual, procedural, metacognitive) was added.

| Domain | Levels (low → high) |
|---|---|
| Cognitive (Bloom 1956) | as above |
| Affective (Krathwohl, 1964) | Receiving, Responding, Valuing, Organisation, Characterisation by a value |
| Psychomotor (Simpson) | Perception, Set, Guided response, Mechanism, Complex overt response, Adaptation, Origination |
| Psychomotor (Dave) | Imitation, Manipulation, Precision, Articulation, Naturalisation |

- **ABCD behavioural objective**: Audience, Behaviour (observable verb), Condition, Degree. "Given a list (C), the student (A) will sort it with bubble sort (B) without error (D)."
- Instructional objective = teacher's intended target for a lesson; learning outcome = what the learner can actually demonstrate at the end of a stage (NCERT term).

**NCF 2005 and NEP 2020**

| NCF 2005 (chair Prof. Yash Pal) | NEP 2020 (approved 29 July 2020; Dr K. Kasturirangan committee) |
|---|---|
| Connect knowledge to life outside school | 5+3+3+4: Foundational (ages 3–8), Preparatory (8–11, Classes 3–5), Middle (11–14, Classes 6–8), Secondary (14–18, Classes 9–12) |
| Move away from rote learning | Coding and computational thinking from Class 6 |
| Enrich curriculum beyond textbooks | Vocational education from Class 6, 10 bagless days, internships |
| Flexible exams integrated with classroom life | PARAKH as national assessment centre; 360° Holistic Progress Card |
| Constructivist, child-centred learning | 21st-century skills: critical thinking, creativity, collaboration, communication, digital literacy |
| — | Mother tongue as medium at least till Class 5; board exams test core competencies, two attempts |

**Curriculum organisation**

| Type | Meaning |
|---|---|
| Logical | Subject's own order, simple to complex as experts see it |
| Psychological | Learner's interests, age and abilities decide the order |
| Concentric | Same topics repeated in each class with widening content |
| Spiral (Bruner) | Return to the same idea at higher levels of abstraction (Scratch loops in Class 6 → Python loops in Class 11) |

## 2. Planning

| Plan | Span | Key point |
|---|---|---|
| Year plan | Session | Units distributed over months, holidays, tests |
| Unit plan ⭐ Asked in DSSSB | A unit (2–4 weeks) | Form units/sub-units if the syllabus does not, content analysis, objectives, learning experiences, methods and aids, **methods of assessment** (unit test) |
| Lesson plan | One period | Specific objectives and step-by-step activities |

**Lesson plan — Herbartian five steps ⭐** (formalised by Herbart's followers Ziller and Rein)

| Step | Example: loops |
|---|---|
| 1. Preparation | Link previous knowledge, motivate, state aim |
| 2. Presentation | Teach the `for` loop with live code |
| 3. Comparison / Association | Compare `for` and `while` |
| 4. Generalisation | Students state the rule |
| 5. Application | Solve a new problem; then recapitulation and home assignment |

- Modern format: general and specific objectives, previous knowledge, teaching aids, introduction (motivating questions), statement of aim, presentation (teacher activity / pupil activity / board work), recapitulation, home assignment.

**Micro-teaching** (Dwight Allen, Stanford, 1963)
- Cycle: Plan → Teach → Feedback → Re-plan → Re-teach → Re-feedback.
- Indian model about 36 min: teach 6, feedback 6, re-plan 12, re-teach 6, re-feedback 6; 5–10 pupils; one skill at a time.
- Skills: introducing (set induction), questioning (fluency, probing), explaining, illustrating with examples, stimulus variation, reinforcement, blackboard writing, closure.

**Edgar Dale's Cone of Experience (1946)** — base most concrete, top most abstract: direct purposeful experience → contrived (models) → dramatised → demonstrations → field trips → exhibits → TV → motion pictures → recordings, radio, still pictures → visual symbols → verbal symbols (top).

## 3. Methods and approaches ⭐

| Method | Key point |
|---|---|
| Lecture | Teacher talks; fast, passive learners |
| Demonstration | Teacher shows, pupils observe |
| Lecture-cum-demonstration | Most practical for school science and CS theory |
| Project ⭐ | W. H. Kilpatrick (1918, Dewey's pragmatism); steps: situation, purposing, planning, executing, judging, recording; **students decide objective and plan** |
| Problem solving | Dewey: sense, define, collect data, hypothesise, test, conclude |
| Inductive | Examples → rule (specific to general); good for beginners |
| Deductive | Rule → examples; quick, for revision |
| Heuristic ⭐ | H. E. Armstrong; Greek *heurisko*, "I find out"; pupil as discoverer |
| Laboratory | Learning by doing on computers |
| Discussion | Panel, seminar, symposium, debate |
| Team teaching | Two or more teachers plan and teach together |
| Programmed instruction | Skinner (linear), Crowder (branching), Gilbert (mathetics); small steps, instant feedback |
| Computer-assisted instruction | Drill, tutorial, simulation, games |
| Peer tutoring / cooperative | Jigsaw (Aronson), think-pair-share, pair programming |
| Inquiry | Suchman's inquiry training; questions drive learning |
| Constructivism ⭐ | Learners construct meaning; **5E**: Engage, Explore, Explain, Elaborate, Evaluate |
| Activity-based | Learning by doing (Dewey) |
| Play-way ⭐ | Froebel (kindergarten), Montessori, Caldwell Cook (*The Play Way*, 1917) |

**Pedagogical approaches ⭐**

| Teacher-centred | Learner-centred |
|---|---|
| Lecture, transmission, passive pupils | Learning by doing, activities, meaning-making ⭐ |
| Teacher as authority | Teacher as facilitator |
| Behaviourist | Constructivist |

- **Subject-centred ⭐**: teacher and pupils confined strictly to the prescribed content/textbook.
- **Methods of teaching science ⭐**: same families — lecture, demonstration, lecture-cum-demonstration, heuristic, project, laboratory, problem solving, inductive–deductive, historical/biographical, assignment.
- **Teaching of writing ⭐**: lower (controlled) forms = copying, dictation, picture composition, guided writing; higher forms = paragraph, essay, letter, free composition (DSSSB key: paragraph writing is NOT a lower form). Reading: loud vs silent; intensive vs extensive.
- **Art education ⭐**: covers **both** visual/tangible arts (drawing, painting, sculpture, craft) and performing arts (music, dance, drama). Art-integrated learning (NEP 2020) uses art to teach other subjects (draw a flowchart as a comic strip).

## 4. CS lab and classroom management

| Area | Practice |
|---|---|
| Layout | U-shape or rows so the teacher sees every screen; projector visible; aisles clear |
| Safety | Earthing, no water/food, covered cables, CO2 fire extinguisher, UPS, master switch |
| Ergonomics | Screen at eye level, about an arm's length away, adjustable chairs, glare-free light |
| Maintenance | Stock register, AMC, dust covers, fault log book |
| Scheduling | Timetable per class; at most two pupils per computer |
| Rules | Displayed rules; no installing software; log off; acceptable-use policy |
| Data | Regular backups, updated antivirus, restricted admin rights, firewall |
| Software | FOSS — Linux, LibreOffice, Python, GIMP, Scratch: no licence cost, legal copying |
| Records | Practical file, lab attendance, issue register |
| Group work | Mixed-ability pairs, rotating roles |

**Classroom management ⭐**
- Rules framed with pupils; routines for entry, distribution, exit.
- Positive reinforcement ⭐ (praise, grades) over punishment; proximity control (stand near the restless pupil); eye contact; time management; "withitness" (Kounin).
- Seating ⭐: child with special needs near the board; group work in clusters; discussion — teacher keeps eye contact with all; performing arts need open space, not a view of the board.

## 5. Evaluation ⭐

| Term | Meaning |
|---|---|
| Measurement | Quantitative only (marks: 42/50) |
| Assessment | Collecting evidence of learning |
| Evaluation | Measurement + qualitative description + value judgement; broadest |

| Type | When / purpose |
|---|---|
| Placement | Before teaching; decide level |
| Formative | During teaching; feedback (assessment FOR learning) |
| Diagnostic | Find cause of persistent errors → remedial teaching |
| Summative | End of term; grading (assessment OF learning) |
| Assessment AS learning | Learner monitors own learning (self-assessment, reflection) |

- **Assessment FOR learning ⭐**: teacher-led feedback, **peer assessment** (classmates judge a learner's response), self-assessment, questioning, exit tickets.
- CCE: Section 29 of RTE 2009; scholastic + co-scholastic areas; formative + summative.
- NEP 2020: competency-based, regular formative assessment; PARAKH (under NCERT) sets norms; Holistic Progress Card.

**Tools**: achievement test, rubric (criteria × levels), checklist (yes/no), rating scale (degree, e.g. Likert), portfolio, anecdotal record, observation, practical exam and viva.

**Characteristics of a good test**

| Quality | Meaning |
|---|---|
| Validity | Measures what it intends (content, construct, criterion — concurrent/predictive, face) |
| Reliability | Consistent results (test–retest, split-half, parallel forms, KR-20) |
| Objectivity | Same score whoever marks |
| Usability | Practical: time, cost, ease of scoring |
| Discrimination | Separates high and low achievers |

- A valid test must be reliable; a reliable test need not be valid.

**Questions, blueprint, grading**
- Objective (MCQ, true/false, matching, fill-in) vs subjective (short, long answer).
- MCQ rules: one clear stem, one correct answer, plausible distractors, avoid "all of the above", avoid negatives (or bold them), similar option lengths.
- Blueprint: three-dimensional chart — objectives × content × question type, with marks weightage.
- Item analysis: difficulty and discrimination indices.
- Feedback: specific, timely, descriptive; remedial teaching follows diagnosis.
- Grading: absolute (fixed cut-offs, criterion-referenced) vs relative (curve, norm-referenced). CBSE uses 9-point grades A1–E.
- Standardised test: expert-built, tried out, has norms; teacher-made: for one's own class, informal.

## 6. Child development and learning theories ⭐

**Piaget — cognitive development ⭐** (schema, assimilation, accommodation, equilibration)

| Stage | Age | Key ideas |
|---|---|---|
| Sensorimotor | 0–2 | Senses and actions; object permanence (about 8 months); circular reactions |
| Pre-operational ⭐ | 2–7 | Symbolic/pretend play ⭐, language, egocentrism (three-mountain task), animism, centration, irreversibility, no conservation |
| Concrete operational ⭐ | 7–11 | Conservation, reversibility, decentration, classification, seriation; logic on concrete things |
| Formal operational ⭐ | 11+ | Abstract, hypothetico-deductive, **propositional thinking, idealism, generality of thought** |

- **Horizontal decalage ⭐**: uneven acquisition of conservation — number first, then mass, weight, volume last.
- Piaget's play ⭐: practice/functional (sensorimotor) → symbolic (pre-operational) → games with rules (concrete). Play is natural, biological, universal; **toys are not essential**.

| Theorist | Key ideas |
|---|---|
| Vygotsky | Social constructivism; ZPD (gap between what a child does alone and with help); scaffolding; MKO; private speech |
| Bruner | Enactive → iconic → symbolic; spiral curriculum; discovery learning |
| Gagné | Nine events: gain attention, state objectives, recall prior learning, present content, guide learning, elicit performance, feedback, assess, enhance retention/transfer; eight types of learning (signal → problem solving) |
| Kohlberg | Pre-conventional (1 obedience–punishment, 2 self-interest), Conventional (3 good boy–nice girl, 4 law and order), Post-conventional (5 social contract, 6 universal principles); Heinz dilemma; Gilligan's critique (ethics of care) |
| Bandura | Observational learning (attention, retention, reproduction, motivation); Bobo doll; self-efficacy |
| Gardner | Multiple intelligences (1983): linguistic, logical-mathematical, spatial, musical, bodily-kinaesthetic, interpersonal, intrapersonal, + naturalist |
| Maslow | Physiological → safety → love/belonging → esteem → self-actualisation |

**Erikson (psychosocial)**

| Age | Crisis |
|---|---|
| 0–1 | Trust vs mistrust |
| 1–3 | Autonomy vs shame and doubt |
| 3–6 | Initiative vs guilt |
| 6–12 | Industry vs inferiority |
| 12–18 | Identity vs role confusion |
| Young adult | Intimacy vs isolation |
| Middle adult | Generativity vs stagnation |
| Old age | Integrity vs despair |

**Marcia's identity statuses ⭐** (exploration × commitment)

| Status | Exploration | Commitment |
|---|---|---|
| Diffusion | No | No |
| Foreclosure | No | Yes (accepts parents' choice) |
| Moratorium ⭐ | **Yes, actively experimenting** | Not yet |
| Achievement | Yes | Yes |

**Neo-Freudians ⭐** (kept Freud's core, stressed social/cultural factors)

| Theorist | Idea |
|---|---|
| Alfred Adler | Individual psychology; inferiority complex; birth order |
| Carl Jung | Analytical psychology; collective unconscious, archetypes; introvert/extravert |
| Karen Horney | Basic anxiety; moving toward/against/away from people |
| Erik Erikson | Psychosocial stages |
| Harry Stack Sullivan | Interpersonal theory |

- Freud himself (not neo): oral, anal, phallic, latency, genital; id, ego, superego.

**Behaviourism**

| Name | Idea |
|---|---|
| Pavlov | Classical conditioning (bell → salivation); extinction, generalisation |
| Thorndike | Trial and error (cat, puzzle box); laws of readiness, exercise, effect |
| Skinner | Operant conditioning (Skinner box); reinforcement schedules; programmed instruction |

| Skinner term ⭐ | Action | Effect | Classroom example |
|---|---|---|---|
| Positive reinforcement | Add pleasant | Behaviour ↑ | High grades, praise |
| Negative reinforcement | Remove unpleasant | Behaviour ↑ | Extra homework dropped when work is finished |
| Positive punishment | Add unpleasant | Behaviour ↓ | Scolding, detention |
| Negative punishment | Remove pleasant | Behaviour ↓ | Lab time withdrawn |

- Variable-ratio schedule is the most resistant to extinction.

**Learning styles ⭐**
- VAK: visual, auditory, kinaesthetic (Fleming's VARK adds read/write).
- **Kolb: based on experiential learning** ⭐ — cycle: concrete experience → reflective observation → abstract conceptualisation → active experimentation; styles: diverging, assimilating, converging, accommodating.

**Infant perception ⭐**
- Newborns prefer faces and patterned stimuli (Fantz, preferential looking).
- Neonates discriminate stripes about 1/8 inch wide; by about 3 months, about 1/64 inch ⭐.
- Auditory–visual coordination present **from birth** ⭐ (eyes turn toward a sound).
- Visual cliff (Gibson & Walk, 1960): crawling infants perceive depth.

**Language development ⭐**

| Stage | About |
|---|---|
| Crying, cooing | from about 2 months |
| Babbling | about 6 months |
| One-word (holophrase) | about 12 months |
| Two-word, telegraphic | 18–24 months |
| Sentences, grammar | 2–5 years |

- Fast mapping ⭐: learning a word after one or two exposures (vocabulary spurt).
- Over-extension (over-generalisation) ⭐: "doggie" for every four-legged animal; under-extension: "duck" only for one's own toy duck.
- Chomsky: LAD, universal grammar (nativist); Skinner: imitation and reinforcement; Vygotsky: social; Piaget: thought precedes language.
- Broca's area (speech production, frontal lobe) and Wernicke's area (comprehension, temporal lobe) — both in the **left hemisphere** ⭐ in most people.

**Parenting styles ⭐ (Baumrind; neglectful added by Maccoby & Martin)**

| Style | Warmth | Control | Child outcome |
|---|---|---|---|
| Authoritative | High | High (reasoned) | Confident, competent, well-liked — best |
| Authoritarian | Low | High (power-assertive) | Anxious; may use coercion with peers |
| Permissive | High | Low | Impulsive, low self-control |
| Neglectful | Low | Low | Poorest outcomes |

- Give-and-take relationship with parents → child shows the same with peers ⭐.

**Play ⭐** — Parten (social): unoccupied → solitary → onlooker → parallel → associative → cooperative.
- Adolescence: G. Stanley Hall's "storm and stress"; Elkind's imaginary audience and personal fable.
- Individual differences: heredity × environment; IQ = (MA ÷ CA) × 100.

## Exam traps
1. Revised Bloom: **Create** is highest; Evaluate is 5th — not the reverse.
2. Negative reinforcement **increases** behaviour; it is not punishment.
3. Horizontal decalage = uneven conservation within one stage, not between stages.
4. Propositional thinking and idealism = formal operational, not concrete.
5. "Doggie for all four-legged animals" = over-extension; "duck only for my duck" = under-extension.
6. Broca and Wernicke are both in the **left** hemisphere.
7. Erikson and Sullivan **are** neo-Freudians.
8. Kolb is experiential learning, not inquiry or collaborative learning.
9. Subject-centred (textbook-bound) is different from teacher-centred.
10. The 71st Amendment added Nepali, not Bodo (92nd); *Kesari* was Marathi; Lokhitwadi = G. H. Deshmukh.
